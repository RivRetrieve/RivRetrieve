# Combined French artifact fixtures

`french_combined_artifacts.tar.xz` losslessly packages public outputs generated by
unchanged revision `fd55eee9d32a278b895bc61487452d43564eaed4`. The archive retains
its `capture.py` command and `attestation.json` with original artifact SHA256s.
The tests verify these hashes after extraction. Compression avoids storing ten
copies of the same catalogue evidence.

The capture replays the committed HydroPortail station-own discharge and Hub’Eau
daily discharge recordings through public `find`, `fetch`, `to_bundle` and
`from_bundle`. It includes empty and combined selections, results with and without
receipts, and a revision-7 accumulated store with both services' observations.
These are authentic old identities, not newly generated outputs with changed IDs.
They must be refused without reading observation values or changing saved bytes.

The additional empty selections were captured with unrestricted provider scope.
One contains only USGS definitions, locations and inventories. Its old French
identity exists only in retained catalogue evidence. The public importer must
refuse that context too, without consulting current catalogues.
