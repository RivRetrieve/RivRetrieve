THAIWATER STANDARD

มาตรฐานข้อมูล

Thaiwater Standard

น้ำฝน น้ำท่า แหล่งน้ำขนาดใหญ่ แหล่งน้ำขนาดกลาง แหล่งน้ำขนาดเล็ก

คุณภาพน้ำ เพื่อการแลกเปลี่ยน

มาตรฐานข้อมูลน้ำเพื่อการแลกเปลี่ยน

ข้อมูลอ้างอิง

การกำหนดมาตรฐานข้อมูลอ้างอิงช่วยให้หน่วยงานด้านน้ำใช้อ้างอิงในรูปแบบเดียวกัน โดยครอบคลุมด้านต่าง ๆ เช่น หน่วยและสัญลักษณ์, รูปแบบวันเวลา, พิกัดตำแหน่ง, การอ้างอิงหน่วยงาน, และลุ่มน้ำหลัก/สาขา เพื่อให้การแลกเปลี่ยนข้อมูลเข้าใจตรงกัน และใช้งานร่วมกันได้อย่างมีประสิทธิภาพ

รูปแบบและโครงสร้างข้อมูล

รูปแบบและโครงสร้างข้อมูลถูกกำหนดเพื่อให้หน่วยงานต่างๆ เข้าใจตรงกันสำหรับการแลกเปลี่ยนและใช้งานในอนาคต โดยเน้นการรับทราบข้อกำหนดเบื้องต้นของชุดข้อมูล โครงสร้างข้อมูลด้านน้ำแบ่งเป็น 2 กลุ่มหลัก ได้แก่ กลุ่มข้อมูลตรวจวัด (Observation) และ กลุ่มข้อมูลสารสนเทศ (Information)

การเชื่อมโยงข้อมูลและแลกเปลี่ยนข้อมูล

การแลกเปลี่ยนข้อมูลน้ำควรใช้โพรโทคอลที่ปลอดภัยและรักษาความลับ พร้อมการยืนยันตัวตนหลากหลายรูปแบบ โดยใช้รูปแบบ JSON และพัฒนาแอปตามแนวทาง OWASP API Security การตรวจสอบสิทธิ์และความถูกต้องช่วยเพิ่มความปลอดภัยและน่าเชื่อถือ.

การควบคุมคุณภาพข้อมูล

การควบคุมคุณภาพข้อมูลคือกระบวนการรักษาความถูกต้อง, ความสม่ำเสมอ, และความน่าเชื่อถือของข้อมูลผ่านการตรวจสอบและระบุข้อผิดพลาด เช่น ข้อมูลผิดพลาดหรือสูญหาย โดยใช้แฟลกคุณภาพและการตรวจย้อนหลังเพื่อความครบถ้วน การดำเนินการนี้ช่วยให้ข้อมูลพร้อมใช้งานและแลกเปลี่ยนได้อย่างมีคุณภาพตามมาตรฐานที่กำหนด

ธรรมาภิบาลข้อมูล

การบริหารจัดการข้อมูลเพื่อให้มีคุณภาพสูงและปลอดภัยตามกฎระเบียบที่กำหนด เน้นความโปร่งใส การควบคุม และการตรวจสอบการใช้ข้อมูลตามมาตรฐาน เพื่อให้ข้อมูลถูกใช้อย่างถูกต้องและมีประสิทธิภาพ รวมถึงการพัฒนาและปรับปรุงนโยบายเพื่อส่งเสริมการใช้ข้อมูลอย่างเป็นระเบียบ.

คำศัพท์ที่เกี่ยวข้องกับมาตรฐานข้อมูลน้ำ

Ammoniacal Nitrogen

ปริมาณแอมโมเนียซึ่งมักพบในน้ำจากขยะที่มาจากหลุมฝังกลบและของเสีย

API Documentation

เอกสารข้อมูลที่อธิบายฟังก์ชันการทำงาน การใช้งาน API และพารามิเตอร์ต่างๆ

API Management System

ระบบที่ช่วยในการจัดการ API การมอนิเตอร์ และ การควบคุมสิทธิ์การเข้าถึง API

Biochemical Oxygen Demand (BOD)

ปริมาณของออกซิเจนที่แบคทีเรียใช้ในการย่อยสลายสารอินทรีย์ในเวลา 5 วัน ที่อุณหภูมิ 20 องศาเซลเซียส

Chemical Oxygen Demand (COD)

ปริมาณออกซิเจนที่จำเป็นสำหรับการย่อยสลายทางเคมีของสารอินทรีย์และสารอาหารอนินทรีย์ เช่น แอมโมเนียหรือไนเตรตที่มีอยู่ในน้ำ

Chlorophyll

สารประกอบที่พบได้ในส่วนที่มีสีเขียวของพืช โดยพบมากที่ใบของพืชนอกจากนี้ยังพบได้ที่แบคทีเรียที่สามารถสังเคราะห์ด้วยแสงได้ และยังพบได้ในสาหร่ายเกือบทุกชนิด

Data Encryption

การเข้ารหัสลับข้อมูล เพื่อปกปิดรักษาความลับของข้อมูล การเปิดเผยข้อมูลได้จำเป็นจะต้องรู้คีย์ที่ใช้ในการถอดรหัส

Digital Certificate

ใบรับรองดิจิทัล ที่สามารถใช้รับรองบริการต่างๆ ได้เช่น รับรองเว็บไซต์ที่ให้บริการข้อมูล เป็นต้น

มาตรฐานข้อมูลน้ำเพื่อการเตือนภัย

คำศัพท์และนิยามเพื่อการเตือนภัย

การแจ้งเตือนน้ำท่วมและน้ำแล้งแบ่งเป็นหลายระดับ เริ่มจากข่าวสารที่ช่วยติดตามสถานการณ์ เช่น ฝนตกหนักหรือระดับน้ำเพิ่มขึ้น สู่การแจ้งเตือนเหตุการณ์เพื่อเตรียมพร้อมรับมือเมื่อสถานการณ์วิกฤติ และการแจ้งภัยพิบัติร้ายแรงที่สุดสำหรับอพยพหรือปฏิบัติการทันที การใช้สีและสัญลักษณ์ช่วยสื่อสารความรุนแรงให้เข้าใจง่ายขึ้น

ข้อมูลและเกณฑ์ของข้อมูลเพื่อการเตือนภัย

ข้อมูลเตือนภัยน้ำท่วมและน้ำแล้งช่วยลดผลกระทบจากภัยพิบัติ โดยใช้ข้อมูลฝนสะสม, ระดับน้ำ, และน้ำในอ่างเก็บน้ำในการแจ้งเตือนตามเกณฑ์ต่างๆ เช่น ฝน, ระดับน้ำท่า, และความจุอ่างเก็บน้ำ การแจ้งเตือนมีสีและระดับความเสี่ยง เช่น เขียว, ส้ม, และแดง.

สถานีและเกณฑ์ของสถานีเพื่อการเตือนภัย

สถานีตรวจวัดน้ำท่วมและน้ำแล้งใช้ระบบอัตโนมัติในการวัดปริมาณฝน, ระดับน้ำท่า, และน้ำในอ่างเก็บน้ำ โดยรายงานข้อมูลทุกชั่วโมงในรูปแบบ dynamic. ข้อมูลมีมาตรฐาน 5 ระดับ โดยสามารถส่งข้อมูลทันทีในสถานการณ์เร่งด่วน.
