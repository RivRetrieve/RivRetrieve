## Evidence Rules

- Behavioral rows cite named tests from `tests/`.
- Structural/process rows are labeled `structural/process` and cite repository artifacts plus structural controls.
- §19 rows are labeled `deferred`; their tests prove absence, not implementation.
- No row cites live network behavior. V1 verification is offline.
