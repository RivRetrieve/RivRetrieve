# Never interpret a licence

RivRetrieve surfaces a link to each source's licence and, where the source publishes
one, its verbatim text. It does not classify, summarise, normalise or otherwise
interpret what a licence permits.

The original proposal included a short structured status such as open, attribution or
restricted, on the reasoning that what a user most often needs to know is whether the
data may be redistributed, and that a bare URL cannot be filtered. That was rejected
for two reasons. We are not lawyers, and while some sources use common licences, others
write custom terms specific to the agency, so any classification is our reading rather
than the source's statement. More durable: a licence we classified once becomes a
licence we must keep re-reading, because when a source changes its terms our stale
interpretation is still sitting in the catalogue with our name on it. Publishing only
what the source itself published has no such maintenance obligation.

The accepted cost is that a user cannot filter providers by redistribution status. They
follow the link and read the terms, which is the correct place for that judgement to be
made anyway.
