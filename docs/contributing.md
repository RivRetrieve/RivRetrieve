# Contributing

Bug reports, questions and suggestions for new data providers are welcome in
[GitHub issues](https://github.com/RivRetrieve/RivRetrieve/issues).

For a bug, include the RivRetrieve version, a small reproducible example, the
provider and station identifiers, requested dates, and the error or unexpected
result. Remove credentials and restricted source material before posting.

For a provider suggestion, share agency links and describe the data you need.
Scripts you have personally used to retrieve that data are useful starting points;
remove credentials and restricted responses before sharing them. You do not need
to supply a complete provider implementation.

Discuss a proposed change in an issue before submitting a pull request. Pull
requests are welcome after that discussion. For an agreed change, use the
[development instructions](development-conventions.md) and
[testing guide](maintenance/testing.md). Provider pull requests carry code, synthetic
fixtures and safe, exact archive references. Retained source corpora, acquisition
records and source-certification tools belong in the private archive. Follow the
[evidence workflow](maintenance/evidence.md) for review and verified input selection.
