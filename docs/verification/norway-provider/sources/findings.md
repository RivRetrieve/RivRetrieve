- API documentation says nonexistent series are omitted; existing series without data return metadata and an empty data element. This distinguishes source absence from request errors and does not establish null-value behavior.
- API documentation has conflicting broad preferred-version language versus its more specific VersionNumber section, which supports explicit versions and says newest data is returned by default if multiple versions exist. Do not infer preferred quality from version numbers.

Its response example places license in the JSON response envelope, despite calling this a response header. Do not assert it is an HTTP header.
- NLOD landing page links version 2.0. Section 5 requires attribution and a licence reference, links to source and licence where practical, and indication of changes. The optional wording in HydAPI does not eliminate these licence requirements. Section 9 qualifies compatibility: CC BY 3.0 compatibility differs for databases. Prefer NLOD plus its link over an unqualified CC BY equivalence.
- NVE publication guidelines dated 2026 establish availability restrictions: historical data from publicly funded and mandated private stations are published; voluntary private-data owners decide publication. Real-time publication can be restricted for regulated catchments, reservoirs and hydropower measurements. Quarantine listed: stage/discharge 14 days, reservoir/power-plant data 3 months, snow 6 months; owner approval can allow earlier publication. Do not imply all recent observations are public or uniform real-time availability.
