# Brazil provider documentation verification

The historical verification records for the Brazil provider introduction are
retained in the private [source archive](https://github.com/RivRetrieve/verification-evidence).
They include source research, quotations, live outputs and regression results.
Retrieve the exact records using the archive instructions. Their historical
`docs/verification/brazil-provider/` paths identify archive members, not local
code-tree inputs. Historical observations do not establish current availability.

The maintained `examples.py` script contains the public API examples.
`catalogue.py` checks packaged discovery without contacting ANA.
Run live examples only from an intentionally credential-provisioned environment.
Keep stdout, stderr and any returned source values in a private directory outside
the checkout. Do not copy credentials into a worktree.

For offline parser and catalogue checks, follow
[Brazil catalogue maintenance](../../../maintenance/catalogue/br_ana/README.md).
The scripts and source interpretation remain here; retained source bodies and
historical execution records belong in the archive.
