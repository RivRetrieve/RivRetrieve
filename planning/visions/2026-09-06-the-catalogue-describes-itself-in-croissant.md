# Vision: the catalogue describes itself in Croissant

Program: https://github.com/RivRetrieve/RivRetrieve/issues/6
Effort: https://github.com/RivRetrieve/RivRetrieve/issues/91

## Goal / Why

Each of the thirteen providers ships a packaged catalogue: stations with coordinates, the
products each source publishes, and which station carries which product. Effort 8 made
every catalogue column declare where its value comes from, and Effort 51 recorded, per
fact, which body issued it, how RivRetrieve acquired it, and the source's exact licence
and citation words. If that chain is missing, the value is withheld rather than shipped.

All of that is written in RivRetrieve's own vocabulary, in a `provenance.json` whose
schema only RivRetrieve's code reads. A dataset crawler, a catalogue site, an agent, or a
researcher's script that has never heard of RivRetrieve cannot learn from the wheel what
the tables are, whose data they hold, under what terms, or why a column is empty.

This vision gives every packaged catalogue one standard descriptor, an
[MLCommons Croissant](https://docs.mlcommons.org/croissant/docs/croissant-spec.html)
JSON-LD document generated by the same network-free build that produces the catalogue
tables, from the same provenance and origin records that certify them. Croissant already
has slots for licence, citation, creator, version, date, file digests, and per-column
lineage to a source file. It has no slot for a deliberate absence, so RivRetrieve adds
exactly one extension property for that.

It also closes a live defect. Six providers hold verified licence and citation statements
in provenance, yet the runtime reads `provider.json`, where generators hardcode both as
null, so a USGS result today reports that the licence is not established when it is.

Success is observable in four ways. A validator that knows nothing of RivRetrieve accepts
all thirteen descriptors. A machine following any canonical column lands on the file and
issuing body it came from, with that body's verbatim terms. Every deliberate absence names
its kind and its evidence or reason. And a Python user reads the same words through one
function.

## What the reader sees

A machine reads the descriptor shipped beside each catalogue:

```json
{
  "@context": {"@vocab": "https://schema.org/", "cr": "http://mlcommons.org/croissant/", "rr": "<RivRetrieve namespace>", "...": "..."},
  "@type": "sc:Dataset",
  "name": "rivretrieve-pl_imgw-catalogue",
  "conformsTo": "http://mlcommons.org/croissant/1.0",
  "version": "2025-10-10",
  "datePublished": "2025-10-10",
  "creator": [{"@type": "Organization", "name": "Instytut Meteorologii i Gospodarki Wodnej"}, {"@type": "Organization", "name": "Global Runoff Data Centre"}],
  "distribution": [
    {"@type": "cr:FileObject", "@id": "stations.parquet", "contentUrl": "stations.parquet", "encodingFormat": "application/vnd.apache.parquet", "sha256": "..."},
    {"@type": "cr:FileObject", "@id": "imgw-native-table", "contentUrl": "https://github.com/RivRetrieve/RivRetrieve/blob/<revision>/src/rivretrieve/_internal/providers/pl_imgw/catalogue/native.parquet", "sha256": "...", "creator": {"@type": "Organization", "name": "Instytut Meteorologii i Gospodarki Wodnej"}, "license": "<verbatim source words>", "citation": "<verbatim source words>"},
    {"@type": "cr:FileObject", "@id": "grdc-metadata-workbook", "sha256": "dfab6ea7...", "creator": {"@type": "Organization", "name": "Global Runoff Data Centre"}}
  ],
  "recordSet": [
    {"@type": "cr:RecordSet", "@id": "stations", "field": [
      {"@type": "cr:Field", "@id": "stations/latitude", "dataType": "sc:Float", "source": {"fileObject": {"@id": "grdc-metadata-workbook"}, "extract": {"column": "..."}}},
      {"@type": "cr:Field", "@id": "stations/crs", "dataType": "sc:Text", "rr:absence": {"kind": "withheld", "reason": "no_acquisition_record_established"}}
    ]}
  ]
}
```

A Python user reads the same document:

```python
import rivretrieve as rr

rr.describe("pl_imgw")["creator"]                     # both issuing bodies, by name
rr.describe("ch_foen")["recordSet"][2]["field"][4]    # crs: rr:absence kind not_published, with the evidence link
rr.fetch(sel, start="2024-01-01", end="2024-01-31").provenance.license
# verbatim source words for usgs_nwis, and no provenance.license_not_established issue
```

## Settled decisions

1. **One Croissant descriptor per provider**, committed beside the other catalogue
   artefacts and shipped in the wheel, produced by the same pure build as the parquet
   files. It is derived from `provenance.json`, the provider's origin declarations, and
   the built tables. It is never hand-edited, and a build that cannot derive it fails.
2. **Date stamps only.** `datePublished` and `version` are the catalogue date that
   `catalogue_version` carries today. The acquisition instants already recorded per
   source, and the per-row `last_catalogue_check` column, are carried as facts. No
   freshness threshold, warning, error, age, or expiry vocabulary exists anywhere. This
   overrides the dbt `loaded_at_field` / `warn_after` / `error_after` clause of the
   retired ADR 0014; `CONTEXT.md`'s source-vintage entry already bans the words.
3. **Pinned public URLs are legitimate.** The repository becomes public with v0.1.0 on
   PyPI. A native table that does not ship in the wheel is identified by its
   commit-pinned GitHub URL, byte size, and sha256, exactly as `NativeTableIdentity`
   records them. Files that do ship get a relative `contentUrl` inside the wheel and a
   sha256. Nothing is uploaded anywhere new.
4. **Per-source credit.** Each issuing body's material is its own `FileObject` carrying
   that body's verbatim licence and citation as ordinary schema.org properties, and each
   canonical field's `source` points at the file of the body that issued it. Poland's
   coordinates trace to the GRDC workbook, identified by the digest Effort 51 verified,
   and its identity to IMGW's table. Private evidence is identified by digest and never
   distributed or linked. Dataset-level `creator` lists every issuing body; dataset-level
   `license` and `citation` are present only when a single body issued everything.
5. **One extension property, `rr:absence`.** It is the only non-standard vocabulary. On
   a field it carries `kind` of `not_published` with the evidence link the origin gate
   already requires, or `kind` of `withheld` with the recorded reason. On a record set
   it carries `kind` of `withheld` with the reason and the number of rows withheld.
   The two kinds are never conflated: a source's silence and RivRetrieve's own gap are
   different facts, as `CONTEXT.md` defines [[unknown]].
6. **The upstream proposal is drafted, not filed.** A repository document under `docs/`
   states the field-level absence vocabulary, grounded in the thirteen shipped
   descriptors and in mlcommons/croissant#1012, which asks for dataset-level bias notes
   rather than field-level absence. Filing it with MLCommons is the maintainer's act.
7. **One new public function, `describe(provider)`**, returns the descriptor as the
   parsed JSON-LD mapping. It widens the surface Effort 14 fixed, deliberately; nothing is
   on PyPI to break. It reads the packaged file and performs no network access.
8. **Licence and citation have one source.** Result provenance and the descriptor draw
   from the verified source statements in provenance. A provider whose statement is
   verified no longer emits `provenance.license_not_established` or
   `provenance.citation_not_established`; a provider with no statement still does.
   Whether `provider.json` keeps its `license`, `citation`, and `catalogue_version`
   fields as build outputs or loses them is the implementer's call, with the constraint
   that the words cannot be written twice.

## Scope — In

- The descriptor generator inside the shared catalogue build, and the committed
  descriptor for each of the thirteen providers, Brazil included: its descriptor states
  truthfully that its catalogue facts are withheld.
- Croissant validation of every committed descriptor in the test suite and CI.
- The `rr:absence` property and its documented shape.
- `describe(provider)` on the public surface.
- Licence and citation flowing from provenance statements into result provenance and the
  descriptor, and the corresponding change to the not-established issues.
- The upstream proposal document.
- `CONTEXT.md` entries for the descriptor and the absence vocabulary, and
  `docs/catalogue-provenance.md` gaining the descriptor as a fourth evidence home.

## Scope — Out (explicit non-goals)

- **Interpreting, classifying, or summarising any licence.** Words are carried verbatim.
- **Redistributing native tables** or any private evidence. Effort 51's ruling stands.
- **Any freshness concept**, however named.
- **Filing the upstream proposal.**
- **Changing what is certified or withheld.** France ships three stations and withholds
  7,320; the descriptor reports that, it does not repair it.
- **Describing observation data.** The descriptor covers the four catalogue tables.
- **Embedding descriptors in web pages** for dataset search. Effort 18 owns the site.
- **Publishing the package** or making the repository public. Effort 9 owns release.
- **A Croissant validator as a runtime dependency.**

## Constraints

- **The build stays pure and reproducible.** No wall-clock value enters the descriptor;
  every date is a committed fact. Re-running a provider's network-free build from its
  committed native table and origins reproduces the descriptor byte for byte.
- **Validation uses the reference validator, `mlcroissant`, as a development dependency
  only.** It imports on Python 3.13 and pulls in pandas, scipy, networkx, rdflib, absl and
  etils, which is why it must never reach `[project.dependencies]`. `jsonschema` is
  already a runtime dependency and may guard RivRetrieve's own structural expectations.
- **Types cannot lie.** `kind` is a named literal, never a boolean. A descriptor field
  carries either a `source` or an `rr:absence`, never neither and never both.
- **Fail loud.** A provenance record without a statement for a body that issued material
  is not an error, it is an absent licence; a canonical column with neither an origin nor
  a withheld fact is an error and the build stops.
- **Authority narrows.** `describe` resolves the packaged path at the composition root;
  the generator receives the provenance, origins, and tables as arguments.
- **The Croissant 1.0 vocabulary is used as published.** Extra schema.org properties on
  a `FileObject` are standard JSON-LD; `rr:` is the only namespace RivRetrieve owns.
- **`CONTEXT.md` is the glossary of record.** Cite code and `CONTEXT.md`, not ADR numbers.
  `tests/test_domain_context.py` pins glossary wording and follows any new entry.

## Repository facts the implementer needs

- Each provider's catalogue lives at
  `src/rivretrieve/_internal/providers/<provider>/catalogue/` as `provider.json`,
  `products.parquet`, `stations.parquet`, `station_products.parquet`, `provenance.json`,
  and `native.parquet`. `pyproject.toml` excludes `native.parquet` from wheels.
- `provider.json` holds `provider_id`, `name`, three live flags, `bulk_observations`,
  `catalogue_version`, `license`, `citation`. Generators write `license` and `citation`
  as `None` (`usgs_nwis/generate_catalogue.py:851`); only `no_nve` carries values.
  `catalogue_version` is `2026-08-02` for most providers, `2025-10-10` for `pl_imgw`,
  `2026-08-01` for `lt_lhmt`, `2026-09-04` for `no_nve`, and null for `br_ana`.
- `provenance.json` is the `AcquisitionProvenance` model in
  `_internal/acquisition_provenance.py`: `native_table` identity with repository path,
  revision, sha256, byte size and semantic digest; `source_records` each with `issuer`,
  `operator`, `acquisitions` (`requested_from` URLs and retrieval instants), `evidence`
  recordings, and `statements` of kind `license`, `citation`, `terms`, or `access` with
  `exact_text` and a verification status; `fact_bindings` tying facts to a source
  acquisition or to a RivRetrieve transformation; and `withheld_facts` with reasons and
  `catalogue_rows` locators.
- Verified public statements exist for `usgs_nwis`, `ca_eccc`, `ch_foen`, `cz_chmi`,
  `fr_hubeau`, `lt_lhmt` (licence and citation), `br_ana` (licence), and `ba_fhmzbih`
  (terms). `pl_imgw` carries a redacted private `access` verification for GRDC, and
  `jp_mlit` and `no_nve` carry their own statements. `th_thaiwater` and `za_dws` have
  none recorded.
- Origin declarations are `STATION_CATALOGUE_ORIGINS` in each provider's `origins.py`,
  typed in `_internal/catalogue_origins.py` as `Field` (native column plus a named
  conversion), `Authored`, `Documented`, `NotPublished(evidence)`, or `Withheld`. Seven
  providers declare `crs` as `NotPublished`: `ba_fhmzbih`, `ch_foen`, `cz_chmi`,
  `jp_mlit`, `no_nve`, `th_thaiwater`, `za_dws`. `pl_imgw` declares `crs` as `Withheld`.
  `ORIGIN_GATE_ENROLLED_PROVIDERS` names twelve; `br_ana` is outside certification and
  ships an empty catalogue with four withheld fact groups.
- Withheld rows today: `fr_hubeau` 7,320 stations, 7,320 observation groups and 33,133
  availability rows out of 7,323 native stations; `ba_fhmzbih` 58 stations of 60;
  `th_thaiwater` 1,648 station-products. `tests/test_provider_row_withholding.py` pins
  the counts.
- `_internal/catalogues/artifact.py` loads the artefact and applies withheld facts;
  `CATALOGUE_FACT_UNIVERSE` enumerates the canonical facts per table. Schemas are in
  `_internal/catalogues/schemas.py`.
- `_internal/registry.py` builds result provenance from `provider_info` and emits
  `provenance.license_not_established` and `provenance.citation_not_established` as
  `info` issues at lines 182 and 320; `tests/test_internal_registry.py` asserts them.
  `CatalogProvenance` in `_internal/results.py` carries `catalogue_version` and the
  whole `acquisition_provenance`.
- The public surface is the thirteen names re-exported in `src/rivretrieve/__init__.py`
  from `_internal/discovery.py`; `describe` joins them there.
- `docs/catalogue-provenance.md` owns catalogue maintenance conventions and names the
  three evidence homes; `docs/provider_ports/<provider>.md` holds per-provider rationale.
- The catalogue build is per provider: `generate_catalogue.py` with
  `--withhold-uncertified --catalogue-date <version> --out <catalogue dir>`, run
  network-free from the committed native table.

## Decomposition hints

1. **Descriptor shape first, against one provider with the richest provenance.**
   `pl_imgw` has two issuing bodies, a private-evidence file, a withheld field, and a
   dated historical acquisition; a descriptor that is right for Poland is right in the
   hard cases. Validate it with `mlcroissant` before generalising.
2. **Then the generator inside the shared build**, a pure function from provenance,
   origins, and tables to the descriptor, and the thirteen committed outputs.
3. **Absence and withheld counts** against `ch_foen`, `fr_hubeau`, and `br_ana`, whose
   states differ in exactly the ways the vocabulary must express.
4. **Licence and citation unification**, the registry issues, and their tests.
5. **`describe`**, the glossary entries, the maintenance document, and the proposal.

## Open questions / risks

- **Validator tolerance.** `mlcroissant` may warn on schema.org properties it does not
  model on a `FileObject`, such as `creator` or `license`. A warning is acceptable; an
  error means expressing per-source terms through a property it does accept, and the
  vision's requirement is the traceability, not the property name.
- **Descriptor size.** France withholds 7,320 stations. The record-set-level count keeps
  the descriptor small; a per-row listing would not, and is not required.
- **The `rr:` namespace URL** must resolve once the repository is public, since JSON-LD
  consumers may dereference it. Choose a URL under the repository or the future
  documentation site and record it in `CONTEXT.md`.
- **Version reset.** Effort 9 resets the package version from 0.1.49. The descriptor's
  `version` is the catalogue date, not the package version, so the reset does not touch it.
